Análise de Performance de Receita – Delivery

Desenvolvi um dashboard analítico simulando um cenário real do setor de delivery, com foco em performance comercial e análise de canais de venda. 

🎯 Problema de negócio
 Como os canais de venda contribuem para a receita total? Existe dependência excessiva de um único canal? O crescimento é sustentável?

📈 Principais insights
• O Marketplace concentra mais de 75% da receita total, mantendo crescimento consistente ao longo do período analisado.
 • O Own Channel representa aproximadamente 25% da receita, apresentando maior volatilidade mensal.
 • A alta concentração de receita em um único canal pode indicar risco estratégico, caso haja perda de performance ou mudança nas condições comerciais.

🛠 Abordagem técnica
• Estruturação e modelagem relacional dos dados
 • Cálculo de participação percentual por canal
 • Análise temporal de crescimento (mês a mês)
 • Construção de dashboard executivo no Tableau Public

O projeto demonstra como dados podem ser transformados em direcionamento estratégico para tomada de decisão.
